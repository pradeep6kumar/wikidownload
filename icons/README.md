# Icons for Wiki Table Downloader

This directory should contain the following icon files:
- `icon-48.png` - 48x48 pixel icon
- `icon-96.png` - 96x96 pixel icon

You can create these icons using any image editor. The icons should be green download buttons to match the theme of the extension.

## Icon Specifications
- Format: PNG
- Sizes: 48x48 and 96x96 pixels
- Color: Green (#4CAF50) with white download arrow
- Style: Circular button with download arrow

## Placeholder Icons
Until you create custom icons, you can use any standard download icon. Make sure to name them correctly as specified in the manifest.json file.
