# Icons for Wiki Table Downloader

This directory should contain the following icon files:
- `icon-48.png` - 48x48 pixel icon
- `icon-96.png` - 96x96 pixel icon
- `icon-128.png` - 128x128 pixel icon (required for Firefox Add-ons submission)

You can create these icons using any image editor. The icons should be green download buttons to match the theme of the extension.

## Icon Specifications
- Format: PNG with transparency
- Sizes: 48x48, 96x96, and 128x128 pixels
- Color: Green (#4CAF50) with white download arrow
- Style: Circular button with download arrow
- Border: Light white border for better visibility

## Design Tips for Firefox Add-ons
- Ensure icons have proper padding around the edges
- Use a consistent design across all sizes
- Test your icons against both light and dark backgrounds
- Use the same green color as the download button for brand consistency
- Make the 128px icon especially detailed for the Firefox Add-ons store display

## Placeholder Icons
Until you create custom icons, you can use any standard download icon. Make sure to name them correctly as specified in the manifest.json file.
